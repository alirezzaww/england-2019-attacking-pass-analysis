# Mission: football analytics

## Why
Alireza wants to become a football analyst and build a public research portfolio
that employers and other learners can inspect, reproduce and discuss.

## Success looks like
- Explain event definitions, code, denominators and football interpretations independently.
- Complete practical extensions and document evidence, assumptions and limitations.
- Maintain a reproducible GitHub project and communicate findings to a football audience.

## Constraints
- Learn and run Python locally in Spyder; browser notebooks are not the preferred workflow.
- Move quickly through easy concepts; favour substantive applied tasks over trivial quizzes.
- Preserve Soccermatics and StatsBomb attribution and accurately describe guided work.
