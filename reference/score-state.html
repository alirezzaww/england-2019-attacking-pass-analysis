Score state before an action

Leading: team goals > opponent goals. Drawing: equal goals. Trailing: team goals < opponent goals.

Walk events in index order and label the pass with the current score. Apply each goal update when its event is reached. Do not assign earlier passes the final score or the outcome of a later shot.

Within-state qualifying share = selected passes in that state / eligible completed passes in that state × 100. A missing denominator is undefined, not a measured zero.

Confounding: multiple possible explanations vary together. In this project, trailing occurs only against two opponents, so comparing score states alone does not isolate an effect of score.

Check overlap: to compare two states within fixtures, require eligible completed passes in both states in each retained fixture. A positive denominator with zero qualifiers is valid; no exposure gives an undefined share. Pooling the same fixtures still weights them by their pass counts, so inspect separate fixture results too.
