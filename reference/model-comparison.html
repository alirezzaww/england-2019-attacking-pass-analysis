Test a feature before claiming improvement.

  1. Fix the candidates, sample and primary metric.
  2. Keep a whole fixture out of each fitting subset.
  3. Calculate scaling from fitting rows only; transform validation rows unchanged.
  4. Pool the held-out predictions and compare the same metric.
  5. Select using training validation, then evaluate fresh data when available.

Log loss and Brier score measure probability error; lower is better. They have different scales and should not be numerically compared to each other. Training fit alone is not a validation result. A repeatedly inspected test set becomes a reused development check.

Opening angle is the angle between the two goalpost vectors. State the coordinate conversion and pitch assumptions. More features can worsen validation results; a small negative result does not prove the feature is irrelevant.
