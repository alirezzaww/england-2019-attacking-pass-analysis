Paired match resampling

  1. Summarise each fixture's numerator and denominator for both players.
  2. Draw the same number of fixtures, with replacement.
  3. Use the same draw for both players; repeat all counts when a fixture repeats.
  4. Pool counts before dividing. Record zero-denominator replicates as invalid.
  5. Store the differences and the seed; document the quantile method and assumptions.

A percentile interval uses quantiles of the resampled distribution. It is not a probability of player superiority. More resamples reduce simulation noise; they do not increase the real sample size. Seven selected fixtures do not establish exchangeability or reliable population coverage.

A difference between two percentages is expressed in percentage points. Keep units visible on the chart.
