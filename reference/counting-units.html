Football analytics reference

Choose the unit before counting.

Pass: use match ID plus pass event ID. Represented shot: use match ID plus assigned shot ID. Possession: use match ID, period and possession ID.

Several passes can share one assigned shot. Several shots can share one possession. Grouping changes the unit; it does not create additional evidence.

A shot value repeated on several pass records remains one shot value. Sum it once per represented shot when describing that shot subset. Do not call it pass-created xG, add it repeatedly as separate opportunities, or describe the subset as all team shots.
