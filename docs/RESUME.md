# Résumé presentation

**Project:** England 2019: attacking passing involvement
**Tools:** Python, pandas, NumPy, Matplotlib, mplsoccer, StatsBomb event data

## Wording while the project is in progress

> Developing a reproducible football event-data case study across seven England
> matches, examining passing involvement before shots with per-90 rates, spatial
> visualisations and sensitivity checks on shot-xG thresholds.

## Evidence-backed project bullets

- Applied possession and timing filters to identify 200 completed passes shortly
  before shots across England's seven 2019 World Cup matches.
- Compared contribution using reconstructed playing time and per-90 rates; tested
  how shot-xG thresholds changed selections from 113 to 98 passes.
- Documented methods, limitations and reproducibility checks, connecting player
  comparisons to individual event maps and final-third entry definitions.
