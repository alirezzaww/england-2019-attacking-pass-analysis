# Study, reproduce or contribute

Start with the README, case study and method definitions. Fork this repository to
experiment, or open an issue with a clear question or reproducible discrepancy.
Pull requests are welcome for corrections, accessible presentation, documentation
and well-scoped research extensions.

1. Follow `docs/REPRODUCIBILITY.md` to create your Python environment.
2. Run `python scripts/check_evidence.py` and `python scripts/check_web.py`.
3. For method changes, rerun affected analysis stages, inspect the resulting figures,
   reconcile saved evidence and explain changes to definitions and counts.
4. Document your source, assumptions, limitations and validation in the pull request.

Do not commit virtual environments, credentials, personal files or raw event caches.
Keep provider attribution and licence notices. A passing consistency check does not
establish that a football interpretation is correct. Describe small-sample findings
carefully and distinguish guided work from independent contributions.
